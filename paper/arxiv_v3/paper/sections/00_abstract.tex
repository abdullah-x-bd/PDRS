\begin{abstract}
Finite structured test domains often support exact counting and indexed enumeration, yet practical systems rarely expose these properties through a language-neutral interface suitable for reproducible distributed campaigns. We present Path-Dependent Radix Spaces (PDRS), a compiler and runtime framework that translates finite acyclic dependent schemas into a canonical intermediate representation with exact cardinality, rank, and unrank operations. The underlying construction follows established indexed-enumeration and enumerative-coding principles. PDRS contributes an external schema, independently implemented Python, C, and Rust runtimes, schema-relative object identities, deterministic work allocation, explicit resource controls, and reproducible campaign tooling.

We evaluate semantic correctness, canonicalization, compilation cost, runtime scalability, representation size, sampling behavior, distributed execution, mutation resistance, integrity, schema evolution, and replay semantics. The evaluation uses an independent recursive oracle, a reduced multivalued decision diagram, a native Feat comparison retained from the frozen evidence layer, eight defect distributions, five allocation policies, malformed-IR fuzzing, and curated cross-language mutants. PDRS provides exact object indexing and duplicate-free coordinated assignment. Targeted generators outperform object-uniform sampling under several nonuniform defect objectives, and contiguous rank intervals can produce severe execution-cost imbalance. Dense ranks attain the minimum fixed-width schema-relative identity length, while complete messages require schema identity, framing, and integrity overhead. In the tested schemas, \FrozenRankCorruption\ percent of single-bit rank corruptions in the frozen evidence layer still decoded to valid objects, which confirms that ranks provide weak intrinsic error detection.

FinSpace demonstrates the framework through FIX message generation, option-pricing validation, ISO 20022 conformance, checkpointed execution, and a versioned replay ledger. PDRS reconstructs structured objects exactly under a fixed canonicalization and schema version. Execution-result reproduction additionally requires versioned adapters, environments, oracle configurations, execution parameters, and external-data snapshots. The contribution is a systems realization and empirical evaluation of indexed finite-domain enumeration. It is not a new theory of combinatorial ranking.
\end{abstract}
