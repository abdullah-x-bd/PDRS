\section{Threats to Validity and Limitations}\label{sec:limitations}
\subsection{Construct validity}
The finite schemas approximate classes of structured workloads. They do not represent every industrial dependency. The heterogeneous execution-cost model isolates allocation effects but does not replace a cluster experiment. The historical-like defect distribution encodes edge and transition patterns. It is not a corpus of confirmed historical bugs.

The density experiment separates identity, payload, and complete message size. The schema-specific and PER encodings apply only where the source domain translates without semantic loss. Arithmetic and rANS results depend on declared distributions and block sizes. A different probability model changes expected length. A decoder that already possesses the schema and model has lower overhead than a self-contained message.

\subsection{Baseline validity}
Feat and SciFe are the closest conceptual predecessors. The frozen evidence executes Feat, while the present paper compares SciFe through its published interface and capability set. A larger venue submission would benefit from a complete native SciFe run over every benchmark. The reduced MDD and BDD baselines represent knowledge compilation, but they do not reproduce every d-DNNF or ZDD tool.

Property-based systems target adaptive failure discovery and shrinking. Covering arrays target interaction coverage. Treating unsupported exact-rank operations as numerical losses would misrepresent those systems. The paper therefore reports objective-specific capabilities and outcomes.

\subsection{Statistical validity}
The paired bootstrap uses complete campaigns as independent units. The study still uses one principal synthetic defect domain. Ninety-six comparisons increase the risk of selective emphasis. We report the full matrix and retain 82 uncertain results instead of converting them to ties or wins.

Hosted-runner timings vary. Figures on compilation and rank access show structural trends. They should not be used as universal throughput predictions. Native speedup ratios depend on compiler flags, processor, memory hierarchy, and interpreter version.

\subsection{Mutation validity}
Curated mutants emphasize critical semantics and have explicit witnesses. They do not approximate every realistic implementation defect. Generic mutation tools can generate equivalent or build-invalid mutants. The artifact separates applicable mutants, compile failures, timeouts, and killed mutants. The 100 percent curated score means that the declared critical mutations were detected. It does not prove absence of defects.

\subsection{Real-program validity}
SimpleFIX is an application-layer encoder and parser, not a full session engine. QuantLib boundary observations can reflect documented numerical preconditions. The ISO validators share XSD sources. The experiments did not discover a previously unknown defect. Upstream confirmation remains necessary before a boundary observation becomes a defect claim.

\subsection{Identity and evolution}
A rank has meaning only under a canonicalization version and schema identity. Arbitrary edits do not preserve ranks. Append-only changes at the end of an ordered domain can preserve prior ranks, while early insertion and branch reordering can move every object. Long-lived systems should retain old schemas or introduce an explicit migration map.

\subsection{Integrity and security}
Dense ranks have weak intrinsic error detection. CRC protects against accidental corruption, not malicious modification. A MAC provides authenticity only under a sound key-management and threat model. The experimental message and domain-permutation code is not a standardized security product. Timing measurements also show branch-index variation, so the reference implementation makes no constant-time claim.

\subsection{Replay}
Object reconstruction does not guarantee execution-result reproduction. Numerical libraries can depend on architecture, compiler, calendar, locale, evaluation date, thread configuration, and external data. An environment hash cannot restore a missing market-data snapshot. The ledger reports missing evidence rather than claiming complete execution reproduction.

\subsection{Reproducibility and archive}
The repository contains one-command scripts, lockfiles, workflow definitions, raw observations, figures, and checksums. A permanent DOI requires an immutable release archived by Zenodo. The paper must cite the DOI only after Zenodo mints it. A mutable branch or workflow artifact does not satisfy the permanent-archive requirement.
