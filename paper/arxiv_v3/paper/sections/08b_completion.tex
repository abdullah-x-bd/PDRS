\section{Completion Assessment}\label{sec:scorecard}
The artifact evaluates completion through machine-readable checks rather than a narrative declaration. A check can pass only when its named evidence file exists and an executable invariant succeeds. The internal Phase 10--18 run passes 21 technical checks. The final CI workflow adds actual ASN.1 PER round trips, an external BDD count, and Rust mutation execution before it builds the submission package.

The permanent-archive row is intentionally separate. Repository contents cannot establish that Zenodo has archived a release or minted a resolving DOI. The source therefore leaves the DOI empty until that event occurs. The paper is technically reproducible before the DOI exists, while the strict public-artifact criterion remains pending until the repository owner completes and verifies the archive.

Historical defect evidence follows the same rule. The study records a QuantLib numerical-boundary exception and parser or validator behavior, but it does not convert these observations into confirmed historical defects. The held-out curated mutation set provides strong controlled evidence, not a substitute for upstream-confirmed regressions. A later version may add historical defects only when vulnerable and corrected upstream versions reproduce the documented behavior.
