# Version terminology

The revision uses four distinct identifiers:

- **Published PDRS package:** `pdrs==0.2.0`
- **Frozen PDRS evidence source:** commit `a2f0449c254f8d222a7fcb62b34367ec532ce7a9`
- **Published FinSpace package:** `finspace==0.1.0`
- **Frozen FinSpace source:** commit `3760f1480e3ef19e4ff0928ddd6938e04045ab1b`

The phrase “Version 0.3 evidence” in earlier repository documentation described functionality on the repository branch. It did not identify a published `pdrs==0.3.0` package. The manuscript therefore cites source commits for experimental evidence and package versions only for public installation.
